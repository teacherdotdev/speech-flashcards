Pictures we drew ourselves, for words where no ARASAAC pictogram fits. Use one
in a pack as `pictogram: "custom/<file name without .png>"`. These are part of
the app (Apache-2.0), not ARASAAC.

- `red-square.png`: a plain red square in ARASAAC's red (#e11206) with a black
  outline, replacing ARASAAC's red paint splash, which looked like blood.
